# takedown-watcher watchlist
#
# One entry per line, fields separated by "|":
#
#   target | reported | note
#
#   target    A domain (example.com) or a full URL (https://example.com/login).
#             A bare domain is checked as https://<domain>/.
#   reported  Optional. The date you sent abuse reports, as YYYY-MM-DD (UTC).
#             Used for approximate time to the first action indicator. Leave blank for none.
#   note      Optional. Free text: who you reported to, a case number, etc.
#
# Lines starting with "#" and blank lines are ignored. Add as many entries as
# you like; nothing depends on how many are listed here.
#
# This repository is public, so everything in this file is visible to anyone.
# Only list domains you are comfortable naming publicly.
#
# The entries below are safe demonstration targets, not real abuse cases.

# Control: an IANA-reserved domain that should always stay up.
example.com |  | Control entry - should always report "live"

# Another IANA demonstration control.
example.org | | Demonstration control - no abuse report was made

# A full URL rather than a bare domain.
https://example.net/login | | Demonstration control - an HTTP 404 is not a takedown

# The .invalid TLD can never resolve, so this shows the "NXDOMAIN" state
# without implying any registrar action.
takedown-demo.invalid | | Demonstration control - reserved nonresolving name, never a registered domain
